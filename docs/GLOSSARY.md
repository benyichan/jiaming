# 术语表：大白话解释本项目用到的一切概念

> 本文档面向维护者与贡献者。你不需要懂命理也能完全维护这个项目——每个概念一段大白话，附争议声明。

## 取名规则（R1~R10）

| 规则 | 大白话 | 属于哪一层 |
|---|---|---|
| R1 规范汉字 | 名字用字必须在国务院《通用规范汉字表》（2013，8105 字）内，否则上不了户口 | 事实（FACT） |
| R2 避讳字 | 汉族传统：晚辈不用长辈名字里的字。字表由用户自己填 | 文化惯例 |
| R3 字辈 | 家族排行的固定用字（如「永世传芳」），由用户自己填 | 文化惯例 |
| R4 多音字 | 「行」「柏」这种字容易被叫错。白名单 = 人名里几乎只读一个音的字 | 事实（字库标注） |
| R5 声调配平 | 平仄交替读起来有起伏，三字同调像念经，末字去声/阳平收尾更响亮 | 语言学通则 |
| R6 字形搭配 | 相邻字笔画差太大难写；三字都是同结构（比如全包围）写出来单调 | 书写美学通则 |
| R7 谐音扫描 | 姓+名连读撞上脏话/疾病/不雅词。判定口径：**声韵母全同、声调任意即算同音**；强禁忌词淘汰，一般负面词提示 | 事实（拼音比对） |
| R8 爆款降权 | 命中近五年官方报告的热门名/字就提示——今年爆款等于三年后重名重灾区 | 事实（官方公开数据） |
| R9 姓氏连读 | 「史珍香」这类：姓+名首字连读成不雅词。对雷词取前两音节比对 | 事实（拼音比对） |
| R10 家乡话提示 | 普通话过关 ≠ 方言过关。按籍贯查方言雷区表，命中就提示「请长辈念一遍」 | 有争议（CONTESTED） |

## 命理相关（本项目只做「带标签的可选模块」）

- **八字**：出生年月日时各对应一组天干地支（共八个字）。干支纪年月日时是**确定的历法换算**（本项目用 [lunar 库](https://github.com/6tail/lunar-java)计算，这部分算事实）。
- **五行**：金木水火土。八个字各归属五行，数一数哪个多哪个少——这也是确定的计数。
- **喜用神 / 宜补什么**：从五行多少推出「缺什么要补什么」。**这一步是解释体系，不是事实**。命理内部就分扶抑、调候、格局等流派，同一八字不同流派结论可能不同。本项目的实现采用最简单的扶抑计数法，UI 强制标注「民俗文化参考，无科学结论支持」。
- **生肖宜忌**：按生肖规定宜用/忌用偏旁。民俗说法内部无统一标准，本项目 v0.2 未收录，仅显示生肖。

## 为什么坚决不做「五格剖象法」

五格剖象法（三才五格，市面取名 App 打分的通用依据）是把姓名笔画数套进固定的吉凶数理表打分。事实核查：

- 创始人：日本运命学家**熊崎健翁**，约 1918 年创立，1929 年《姓名の神秘》系统化，故又称「熊崎氏姓名学」
- 传入路径：1936 年由台湾留学生白玉光（白惠文）译介进入台湾，后传入大陆
- 关键事实：**1918 年之前的中国典籍中零记载**，与《易经》等传统经典无关
- 结论：它是百年历史的现代发明伪托传统。本项目不做，此决策本身即对行业乱象的表态

参考：[知乎《醒醒吧！风靡全网的"三才五格"起名法》](https://zhuanlan.zhihu.com/p/2061538236997038893)、[百度百科"五格"词条](https://baike.baidu.com/item/%E4%BA%94%E6%A0%BC/4630445)

## 数据标注体系

```kotlin
enum class EvidenceGrade { FACT, CONVENTION, CONTESTED }
```

- `FACT`：客观可验证（规范字表、拼音笔画、典籍原文、官方统计）
- `CONVENTION`：文化惯例，无统一标准但广泛遵循（避讳、字辈）
- `CONTESTED`：体系内部分歧（五行归属、喜用神、方言拟音）。UI 上此类内容必须展示争议说明

每条数据的 JSON 里带 `source` 字段；贡献新数据必须附来源（见 CONTRIBUTING）。

## 谐音判定口径（代码实现与本文保持一致）

- 声韵母全同、声调任意 → 命中
- 命中**强禁忌词**（脏话/性/疾病/严重不雅）→ FAIL（淘汰级）
- 命中一般负面词（死/病/穷等大众忌讳）→ WARN（提示级）
- 仅声母或仅韵母相同 → 不告警（21 声母 24 韵母的粒度下无区分度，全开等于对所有名字误报）
- 为什么单字强禁忌几乎不收：中文同音字太多，「世/士/事」与「屎」同音异调，但「世轩」是好名字——单字收强禁忌会大面积误杀
